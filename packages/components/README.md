# @openpresent/components

**Editorial and technical slide primitives.**

Part of [OpenPresent](https://github.com/vamgan/openpresent), a local-first
presentation runtime for AI agents. Your slides are real React files on your
machine, and a validator catches the 12px legend before your audience does.

[![npm](https://img.shields.io/npm/v/@openpresent/components)](https://www.npmjs.com/package/@openpresent/components)

The rhetorical patterns that repeat across decks: hero statements, comparisons, metrics, timelines, code, flows, charts, and reveals. Use a primitive when the pattern repeats, and plain HTML when a slide is specific to your story.

## Usage

```tsx
import { Grid, Metric, Slide } from '@openpresent/components';
import '@openpresent/components/styles.css';
```

Full documentation, including the authoring guide and the validator rule
reference, lives in the [main repository](https://github.com/vamgan/openpresent).
